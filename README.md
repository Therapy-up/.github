# 🧠 Therapy - Plataforma de Telepsicologia

**Therapy** é uma plataforma web desenvolvida para conectar psicólogos e pacientes de forma segura, prática e acessível. A solução permite agendamento de sessões, chat privado, gestão de prontuários, documentos e controle financeiro, tudo em um só lugar.

---

## 🎯 Sobre o Projeto

A **Therapy** nasceu com o propósito de democratizar o acesso à saúde mental, oferecendo uma ferramenta completa e segura para profissionais de psicologia e seus pacientes. Sabemos que a distância e a falta de ferramentas integradas são barreiras significativas no atendimento psicológico, e é por isso que criamos uma plataforma que centraliza todas as necessidades do consultório digital.

---

## 🚀 Tecnologias Utilizadas

| Categoria | Tecnologia |
|-----------|------------|
| **Frontend** | [React](https://reactjs.org/) + [Tailwind CSS](https://tailwindcss.com/) |
| **Backend** | [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/) |
| **Banco de Dados** | [PostgreSQL](https://www.postgresql.org/) |
| **Hospedagem** | Vercel, Render, Railway ou Heroku |

---

## 📦 Funcionalidades Principais

- ✅ **Cadastro e Login** de psicólogos e pacientes com autenticação segura
- 💬 **Chat seguro em tempo real** para comunicação entre profissional e paciente
- 📅 **Agendamento de sessões** com calendário integrado
- 🗂️ **Prontuário digital** com histórico detalhado por paciente
- 📄 **Upload e gerenciamento de documentos** clínicos
- 📊 **Painel de controle** com dados financeiros e relatórios
- 🔐 **Segurança e privacidade** dos dados em conformidade com a LGPD
